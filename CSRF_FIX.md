# Решение проблемы "CSRF token mismatch"

## Причины ошибки:

1. **Сессия не запущена** — `session_start()` не вызван до проверки токена
2. **Токен не передаётся** — форма не содержит поле `_csrf`
3. **Токен устарел** — сессия истекла или была очищена
4. **Cookie проблемы** — настройки браузера блокируют cookies
5. **AJAX запросы** — токен не добавлен в заголовки

## Быстрое исправление:

### 1. Проверьте, что сессия стартует
Откройте `app/bootstrap.php` или `index.php` и убедитесь:

```php
use NetFree\Session;

Session::start(); // Должно быть в начале
```

### 2. Проверьте формы в админке
Все формы должны содержать:

```php
<?= Csrf::field() ?>
```

### 3. Для AJAX запросов
Добавьте токен в заголовки:

```javascript
fetch('/admin/ajax/...', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'X-CSRF-Token': '<?= csrf_token() ?>'
    },
    body: JSON.stringify(data)
});
```
