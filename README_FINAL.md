## 💡 Примеры использования

### Создание лендинга за 5 минут
```
1. Вставить шаблон "Hero — простой"
2. Вставить шаблон "Преимущества — 3 колонки"
3. Вставить шаблон "Тарифы — 3 плана"
4. Вставить шаблон "Призыв к действию"
5. Вставить шаблон "Footer — простой"
6. Настроить тексты и цвета → Готово!
```

### Акционный баннер (только сентябрь)
```json
{
  "visibility": {
    "enabled": true,
    "rules": [
      {
        "type": "date_range",
        "from": "2026-09-01",
        "to": "2026-09-30"
      }
    ]
  }
}
```

### Контент для подписчиков
```json
{
  "visibility": {
    "enabled": true,
    "rules": [
      {"type": "user_logged", "logged": true}
    ]
  }
}
```

## 🔧 Настройка

### Включить оптимизацию медиа
```php
SettingsRepository::set('media_optimize', '1');
```

### Включить SVG загрузку
```php
SettingsRepository::set('media_allow_svg', '1');
```

### Добавить свой шаблон (в плагине)
```php
add_action('netfree.register_templates', function($library) {
    $library::register('my-template', [
        'title' => 'Мой шаблон',
        'category' => 'Custom',
        'document' => [ /* ... */ ]
    ]);
});
```
