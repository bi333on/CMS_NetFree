## 📋 Если проблема осталась:

### Вариант A: Включите отладку

В файле `config/app.php` установите:

```php
return [
    'debug' => true,  // Включить отладку
    // ...
];
```

Или создайте константу в `public/index.php` (перед require):

```php
define('NF_DEBUG', true);
```

Теперь CSRF ошибки будут логироваться в error_log PHP.

### Вариант B: Проверьте права доступа

```bash
# В корне проекта:
chmod -R 755 storage/
chmod -R 755 public/uploads/
```

### Вариант C: Проверьте конфигурацию PHP

Убедитесь, что в `php.ini`:

```ini
session.save_path = "/tmp"  ; или любой существующий путь
session.gc_maxlifetime = 1440
session.cookie_lifetime = 0
```
