# NetFree

Модульная PHP-CMS с архитектурой в стиле WordPress: хуки (actions/filters), плагины и защищённый REST API.

## Возможности (MVP)

- Страницы и контент (MySQL), демо-контент «Главная» / «О нас»
- Админ-панель с авторизацией и CSRF-защитой
- Система плагинов через хуки (официальные — в `plugins/`, сторонние — в `storage/plugins/`)
- Защищённый REST API: API-ключи + JWT + HMAC-подпись + rate limit
- Закрытый код: веб-корень = `public/`, ядро вне веб-корня

## Быстрый старт (локально)

1. Создайте базу MySQL, например `netfree`.
2. Откройте `http://localhost:8000/install.php` через встроенный сервер:

```
php -S localhost:8000 -t public
```

3. Заполните форму установки.
