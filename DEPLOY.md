# NetFree — деплой и установка

NetFree — модульная PHP-CMS с архитектурой в стиле WordPress: хуки, плагины и защищённый REST API.

## Требования

- PHP 8.0+
- MySQL 5.7+ / MariaDB 10.3+
- Расширения PHP: `pdo`, `pdo_mysql`, `mbstring`, `openssl`, `json`
- Для установки «одним файлом» дополнительно: `curl`, `zip`

## Структура проекта

```
public/            # единственная точка входа веб-сервера (index.php, install.php)
app/               # ядро CMS (закрыто от внешнего доступа)
config/            # конфигурация (env.php генерируется установщиком)
admin/             # админ-панель (шаблоны, контроллер в app/)
themes/            # темы (default — базовая)
plugins/           # официальные (закрытые) плагины
storage/plugins/   # сторонние (открытые) плагины
storage/           # кэш/логи
```

## Способ 1. Установка «одним файлом»

1. Создайте пустой каталог на хостинге и загрузите туда **только** `netfree-install.php`.
2. Откройте в браузере `https://ваш-домен/netfree-install.php`.
3. Введите URL репозитория GitHub — файлы CMS скачаются и распакуются автоматически.
4. Вас перенаправит на `/public/install.php` — введите данные MySQL и администратора.
5. После установки удалите `netfree-install.php` и `public/install.php`.

## Способ 2. Установка вручную (FTP/SSH)

1. Загрузите все файлы проекта на хостинг.
2. Настройте веб-сервер так, чтобы веб-корень указывал на папку `public/`.
3. Откройте `https://ваш-домен/install.php` и заполните форму.
4. Удалите `public/install.php`.

## Настройка веб-сервера

**Главное правило безопасности:** веб-корень = `public/`. Каталоги `app/`, `config/`,
`admin/`, `plugins/`, `storage/` не должны быть доступны извне.

### Caddy
Используйте готовый `Caddyfile` из корня (веб-корень задан как `public/`).

### nginx
Используйте готовый `nginx.conf` (веб-корень `public/`).

### Apache / общий хостинг
Если веб-корень нельзя изменить (общий хостинг), положите `.htaccess` из корня
в корень проекта — он перенаправляет запросы на `public/index.php` и закрывает
доступ к чувствительным каталогам.

## Админ-панель

- Адрес: `https://ваш-домен/admin`
- Логин/пароль задаются при установке.

## REST API (защищённый)

Базовый путь: `https://ваш-домен/api/v1`.

### Аутентификация
- **API-ключи** (для плагинов): заголовок `X-API-Key: ck_...`
- **JWT** (для внешних клиентов): `Authorization: Bearer <token>`
  - Получить токен: `POST /api/v1/auth` с `{"username":"...","password":"..."}`
- **HMAC-подпись** (опционально): заголовки `X-Nonce`, `X-Timestamp`, `X-Signature`

### Эндпоинты
| Метод | Путь | Описание | Права |
|-------|------|----------|-------|
| POST | `/api/v1/auth` | Получить JWT | — |
| GET | `/api/v1/pages` | Список страниц | любой ключ/JWT |
| GET | `/api/v1/pages/{slug}` | Страница по slug | любой ключ/JWT |
| POST | `/api/v1/pages` | Создать страницу | ключ `write` или роль admin |
| GET | `/api/v1/options` | Настройки сайта | любой ключ/JWT |

### Лимиты
По умолчанию 60 запросов в минуту на клиента (настраивается в `config/env.php`).

## Безопасность

1. Всегда удаляйте `public/install.php` и `netfree-install.php` после установки.
2. Секреты (JWT, HMAC, ключ приложения) генерируются при установке и хранятся в `config/env.php`.
3. Пароли хэшируются через `password_hash` (bcrypt).
4. Админ-панель защищена CSRF-токенами.
5. Держите `app/`, `config/` и `plugins/` вне веб-корня.
